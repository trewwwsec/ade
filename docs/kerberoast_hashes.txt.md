# kerberoast_hashes.txt

Kerberoastable TGS hashes from [[asrep]] (no-auth) and [[kerberoast]] (authenticated).

- **Hashcat mode:** 13100
- **Format:** `$krb5tgs$23$*user$DOMAIN$SPN*$hash`
- **Generated by:** `GetUserSPNs.py`

```bash
hashcat -m 13100 kerberoast_hashes.txt <wordlist>
john --wordlist=<wordlist> kerberoast_hashes.txt
```
