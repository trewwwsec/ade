# users.txt

Username list generated by [[ldap]] and [[smb]].

- One username per line
- Case-preserved originals + lowercase duplicates
- Used by [[asrep]] for roasting and spraying
- Hashcat mode: N/A (not a hash file)

**Crack/spray with:**
```bash
crackmapexec smb <target> -u users.txt -p '<password>' --continue-on-success
```
