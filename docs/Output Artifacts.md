# Output Artifacts

All files produced by ADE during enumeration.

## Directory Structure

```
<output-dir>/
├── ade_summary.txt          # Findings report (summary module)
├── ade_debug_<ts>.log       # Debug log (-v flag only)
├── users.txt                # Enumerated usernames
├── asrep_hashes.txt         # AS-REP roastable hashes
├── kerberoast_hashes.txt    # Kerberoastable TGS hashes
├── gpp_passwords.txt        # Recovered GPP/cpassword credentials
├── laps_passwords.txt       # Readable LAPS local admin passwords
├── nxc_rid_debug.log        # Raw RID brute-force output
├── <username>.ccache        # Kerberos ticket cache
├── certipy/                 # Certipy output directory
│   ├── <date>_Certipy.txt
│   ├── <date>_Certipy.json
│   └── <date>_Certipy.zip
└── <username>/              # BloodHound output
    └── <date>_bloodhound.zip
```

## File Details

### ade_summary.txt
Generated by [[summary]] module. Contains:
- Target information and timestamp
- Artifact inventory with paths
- Attack path suggestions
- Quick reference commands

### users.txt
Generated by [[ldap]] and [[smb]].
- One username per line
- Both case-preserved originals and lowercase duplicates
- Used by [[asrep]] for roasting/spraying

### asrep_hashes.txt
Generated by [[asrep]].  
**Hashcat mode:** 18200  
**Crack:**
```bash
hashcat -m 18200 asrep_hashes.txt <wordlist>
john --wordlist=<wordlist> asrep_hashes.txt
```

### kerberoast_hashes.txt
Generated by [[asrep]] (no-auth) and [[kerberoast]] (authenticated).  
**Hashcat mode:** 13100  
**Crack:**
```bash
hashcat -m 13100 kerberoast_hashes.txt <wordlist>
john --wordlist=<wordlist> kerberoast_hashes.txt
```

### gpp_passwords.txt
Generated by [[gpp]].
- One recovered cleartext password per line
- Only created if credentials were actually recovered

### laps_passwords.txt
Generated by [[laps]].
- One `<computer>:<password>` pair per line
- Only created if any LAPS password was readable with current credentials

### <username>.ccache
Generated by [[smb]] in Kerberos mode.  
**Usage:**
```bash
export KRB5CCNAME=/path/to/loot/user.ccache
smbclient.py -k dc01.corp.local
```

### nxc_rid_debug.log
Raw output from `nxc --rid-brute` for debugging.

### certipy/
Generated by [[adcs]]. Contains:
- `*_Certipy.txt` — human-readable findings
- `*_Certipy.json` — machine-readable data
- `*_Certipy.zip` — BloodHound CE ADCS import

### <username>/
Generated by [[bloodhound]]. Contains a ZIP file for BloodHound CE import.

## Output Directory Behavior

- **Default:** `ade_<IP>_<YYYYMMDD>/` in CWD
- **Custom:** `-o /path/to/loot`
- **Lazy creation:** directory is only created when the first artifact is written
- **Startup failures do not create the directory**
- **Repeated runs** to the same directory append/overwrite files
